# Página Web de Cursos Online - Nexus Academy

## Descripción del proyecto

Este proyecto consiste en una plataforma web de cursos online llamada **Nexus Academy**, diseñada con el propósito de brindar oportunidades de aprendizaje a personas de bajos recursos que desean estudiar, capacitarse y mejorar sus habilidades desde cualquier lugar.

La plataforma busca facilitar el acceso a la educación virtual mediante cursos organizados por edades, interfaces adaptadas para diferentes tipos de usuarios y un sistema de becas que permite a los estudiantes acceder a cursos de manera gratuita.

Además, el sistema cuenta con integración de métodos de pago como **PayPal**, permitiendo que los usuarios que sí puedan pagar accedan a cursos premium, mientras que otros estudiantes pueden postular a becas o beneficios educativos.

---

## Objetivo general

Desarrollar una página web educativa que permita a niños, adolescentes y adultos acceder a cursos online de forma sencilla, interactiva y accesible, promoviendo la educación digital para personas con recursos económicos limitados.

---

## Objetivos específicos

- Crear una plataforma web ordenada, moderna e intuitiva para cursos online.
- Permitir que los estudiantes puedan visualizar cursos según su edad o categoría.
- Implementar una interfaz adaptable dependiendo del tipo de usuario.
- Ofrecer un sistema de becas para estudiantes de bajos recursos.
- Integrar un sistema de pago mediante PayPal para cursos de pago.
- Brindar una experiencia interactiva y amigable para niños, adolescentes y adultos.
- Facilitar el acceso a la educación virtual desde cualquier dispositivo.

---

## Público objetivo

La plataforma está dirigida a:

- Niños que desean aprender de manera divertida e interactiva.
- Adolescentes que buscan reforzar sus conocimientos o aprender nuevas habilidades.
- Jóvenes y adultos que desean capacitarse de forma online.
- Personas de bajos recursos que necesitan oportunidades educativas gratuitas.
- Estudiantes que buscan cursos accesibles desde casa.

---

## Características principales

### Sistema de cursos online

La plataforma permite mostrar cursos organizados en diferentes secciones. Cada curso puede incluir información como:

- Nombre del curso.
- Imagen o portada del curso.
- Descripción del curso.
- Categoría.
- Precio.
- Acceso gratuito mediante beca.
- Botón para ver más información.
- Botón para comprar o inscribirse.

---

### Adaptación de interfaz según la edad

Una de las funcionalidades principales del proyecto es que la interfaz puede adaptarse dependiendo de la edad del usuario.

Por ejemplo:

- Para niños, la interfaz puede ser más colorida, visual e interactiva.
- Para adolescentes, la interfaz puede ser moderna, dinámica y fácil de usar.
- Para adultos, la interfaz puede ser más formal, clara y directa.

Esto permite que cada usuario tenga una mejor experiencia según su etapa de aprendizaje.

---

### Sistema de becas

El proyecto incluye una propuesta de sistema de becas para ayudar a personas que no cuentan con los recursos económicos suficientes para pagar un curso.

Este sistema permite que los estudiantes puedan acceder a cursos gratuitos mediante una solicitud o evaluación de beca.

El objetivo es que la educación no dependa únicamente de la capacidad económica, sino también de las ganas de aprender y superarse.

---

### Cursos gratuitos y cursos de pago

La plataforma puede manejar dos tipos de cursos:

1. **Cursos gratuitos:** disponibles para estudiantes becados o para cursos libres.
2. **Cursos de pago:** disponibles para usuarios que desean adquirir cursos premium.

De esta manera, la plataforma mantiene un equilibrio entre sostenibilidad económica y apoyo social.

---

### Método de pago con PayPal

El proyecto incluye integración o propuesta de integración con **PayPal** como método de pago.

PayPal permite realizar pagos de manera segura y sencilla, facilitando la compra de cursos online para usuarios nacionales e internacionales.
